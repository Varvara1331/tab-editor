      Создание нового пользователя.

      Автоматически хеширует пароль перед сохранением в базу данных.

      Parameters

      • username: string

        Имя пользователя (должно быть уникальным, 3-50 символов)

      • email: string

        Email пользователя (должен быть уникальным, корректный формат)

      • password: string

        Пароль в открытом виде (будет захэширован, минимум 6 символов)

      Returns Promise<IUser>

      Созданный пользователь с автоматически сгенерированным ID

      Throws

      Если не удалось создать пользователя (ошибка БД или дубликат)

      Example

      console.log(`Пользователь ${newUser.username} создан с ID ${newUser.id}`);

    StaticcomparePassword

    • comparePassword(user: IUser, password: string): Promise<boolean>

      Проверка пароля пользователя.

      Сравнивает введённый пароль с захэшированным паролем из базы данных.

      Parameters

      • user: IUser

        Объект пользователя (должен содержать поле passwordHash)

      • password: string

        Пароль для проверки (в открытом виде)

      Returns Promise<boolean>

      true если пароль верный, false в противном случае

      Example

      const user = await UserService.findByEmail('user@example.com');
      const isValid = await UserService.comparePassword(user, 'entered-password');
      if (isValid) {
        // Пароль правильный
        console.log('Успешный вход');
      }
