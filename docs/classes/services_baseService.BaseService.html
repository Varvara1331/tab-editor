    Class BaseService<T>

    Базовый сервис для работы с API ресурсами. Предоставляет стандартные CRUD методы: getAll, getById, create, update, delete.

    Example

    interface User extends Identifiable {
      name: string;
      email: string;
    }

    const userService = new BaseService<User>('/users');
    const users = await userService.getAll();
