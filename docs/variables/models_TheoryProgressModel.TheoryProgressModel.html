    Объект модели TheoryProgressModel с методами для работы с прогрессом.

    Все методы делегируются TheoryProgressService с привязкой контекста. Эта прослойка обеспечивает:

    • Единый интерфейс для контроллеров
    • Возможность легко заменить реализацию сервиса
    • Упрощение тестирования (можно замокать модель)

      Получить прогресс пользователя.

      Param: userId

      ID пользователя

      Returns

      Данные прогресса или null, если пользователь ещё не начинал обучение

      Example

      const progress = await TheoryProgressModel.getProgress(1);
      if (progress) {
        console.log(`Пройдено статей: ${progress.completedArticles.length}`);
      }
    • ReadonlyupsertProgress: any

      Создать или обновить прогресс пользователя. Если прогресс не существует, создаётся новый; если существует - обновляется.

      Param: userId

      ID пользователя

      Param: data

      Частичные данные для обновления

      Returns

      Обновлённые данные прогресса

      Example

      // Обновление последнего времени чтения
      await TheoryProgressModel.upsertProgress(1, {
        lastRead: new Date().toISOString()
      });
    • ReadonlycompleteArticle: any

      Отметить статью как пройденную. Если передан quizScore, добавляет очки в общий счёт пользователя.

      Param: userId

      ID пользователя

      Param: articleId

      ID статьи

      Param: quizScore

      Оценка за тест (опционально, от 0 до 100)

      Returns

      Обновлённые данные прогресса

      Example

      // Отметить статью без оценки

      // Отметить статью с оценкой за тест
      await TheoryProgressModel.completeArticle(1, 'advanced-scales', 95);
