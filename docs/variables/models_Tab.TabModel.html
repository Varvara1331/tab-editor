    Объект модели Tab с методами для работы с табулатурами.

    Все методы делегируются TabService с привязкой контекста. Эта прослойка обеспечивает:

    • Единый интерфейс для контроллеров
    • Возможность легко заменить реализацию сервиса
    • Упрощение тестирования (можно замокать модель)

      Создание новой табулатуры.

      Param: userId

      ID владельца табулатуры

      Param: tabData

      Данные новой табулатуры (title, artist, tuning, measures и т.д.)

      Returns

      Созданная табулатура с автоматически сгенерированным ID

      Example

      const newTab = await TabModel.create(1, {
        title: 'Smoke on the Water',
        artist: 'Deep Purple',
        tuning: ['E', 'A', 'D', 'G', 'B', 'E']
      });

      Получение публичных табулатур с пагинацией и поиском.

      Param: limit

      Количество записей на странице (по умолчанию 50)

      Param: offset

      Смещение для пагинации (по умолчанию 0)

      Поисковый запрос (по названию или исполнителю)

      Returns

      Example

    • Readonlyupdate: any

      Обновление существующей табулатуры. Обновляет только переданные поля, остальные остаются без изменений.

      Param: id

      ID обновляемой табулатуры

      Param: userId

      ID владельца (для проверки прав)

      Param: tabData

      Данные для обновления

      Returns

      Обновлённая табулатура или null, если нет прав доступа

      Example

      // Обновление только заголовка и публичного статуса

        title: 'New Title',
        isPublic: true
      });
